# Данные

В репозитории нет сырых данных. Их расположение указано в файлах `configs/sessions.yaml` и `configs/default.yaml`.

| Файл | Содержимое |
|---|---|
| `../Исходные данные/2_30.zip` | запись видео за первый день |
| `../Исходные данные/Нейронет_30_сентября_группа_2.zip` | Результаты первого дня БиоРадио |
| `../Исходные данные/Результаты.xlsx` | тест Л34 |
| `new/3_7.zip`, `new/БиоРадио.zip` | день второй, исключительно s14 |
| `data/processed/labeling-labeled/` | формы заполненного самоотчёта |

Шаблон находится в `subjects.example.yaml`, а имена вместе с табельными номерами записаны в `configs/subjects.local.yaml`. Пайплайн записывает результаты в директории `data/interim/` и `data/processed/`.

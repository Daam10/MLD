# Методика

## Данные

Записано 10 респондентов из группы 2. Девять человек записали 30.09, а s14 записали 07.10. Запись s03 исключили. Интервью проходит по порядку: вступление, алкоголь, конфликт, обман, завершение. По сценарию одна тема правдивая, одна содержит подготовленную ложь и одна содержит неподготовленную.

| | День 1 | День 2 (s14) |
|---|---|---|
| Видео | ракурс ¾, одна камера 1080i50 | то же |
| БиоРадио | ЭКГ, пояс для дыхания и КГР в режиме насыщения | Дополнение: ФПГ, SpO₂, поток воздуха |
| Самоотчёт | есть | есть |
| Тест Л34 | есть | есть |

## Синхронизация

Для поиска сдвига между видео и БиоРадио используется дыхание. Оптический поток груди сравнивается с показаниями пояса в рамках окон по одной минуте. После этого сдвиг корректируется через пульс, так как сигнал лица коррелирует с R-зубцами ЭКГ. В качестве контроля используются метки кнопки.

## Речь

Для транскрипции используется WhisperX large-v3. Определение ролей происходит на основе WeSpeaker, структуры диалога и локальной LLM. Для каждого ответа вычисляются темп, латентность, доля пауз, параметры Praat, набор eGeMAPS и аномальность голоса по сравнению с вступлением.

## Биосигналы

NeuroKit2 находит R-зубцы после фильтрации ЭКГ. ВСР рассчитывается в окне длительностью 120 с с шагом 5 с. Данные о дыхании берут из пояса и ЭКГ. Контактную ФПГ у s14 обрабатывают тем же кодом, что и ЭКГ. КГР в анализ не включают.

## Видео

Модель RTMW-x определяет позу, при этом длины нормируются относительно длины корпуса. Точки со значениями уверенности ниже установленного порога не учитываются. Метод POS используется для вычисления rPPG по области лба и щек.

## Метки

Значение основной метки `y_self` поступает из самоотчёта. Метка `y_scen` определяется темой сценария, но она плохо согласуется с самоотчётом.

## Статистика

Нормирование признаков происходит внутри каждого человека относительно его ответов во вступлении. Для сравнения лжи и правды по людям используют критерий Уилкоксона с поправкой FDR. Десять маркеров выбраны заранее на основе работ DePaulo и Vrij. Сравнение холериков и флегматиков проводится критерием Манна-Уитни. Связь со шкалами Л34 проверяют через смешанные модели. Тест классификаторов на новом человеке включает перестановочный тест.
